# План разработки NEUROSHIFT

Дата: 13 октября 2026 года.
Цель: яркий адаптивный лендинг-магазин обучения промпт-инжинирингу и работе с ИИ, пригодный для запуска в Container Apps.
Репозиторий исходников: https://github.com/KostyaSemenkov/AI_Knowledge, ветка `main`.

## Архитектура

- Статические HTML, CSS и JavaScript ES modules без runtime-зависимостей и тяжёлого фреймворка.
- Локальные оптимизированные WebP-изображения, системные шрифты, локальные иконки Lucide.
- Nginx в контейнере под непривилегированным пользователем, порт 8080, endpoint `/healthz`.
- Корзина сохраняется в localStorage; каталог и учебные материалы хранятся в исходниках.
- Первая версия готовит и скачивает заявку на обучение. Реальная отправка заявок и оплата подключаются отдельным этапом после выбора провайдера и предоставления реквизитов.
- Исходники версионируются в GitHub. Публикация образа и развёртывание в облаке выполняются отдельным этапом.

## Бюджет и эксплуатация

- Без внешних запросов к шрифтам, аналитике, CDN или AI API при открытии страницы.
- Целевой суммарный вес поставляемых изображений: до 1.5 MB; HTML/CSS/JS: до 150 KB без сжатия.
- Первое изображение загружается приоритетно; остальные используют lazy loading и заданные размеры.
- Предпочтение CSS-анимациям; учитывать prefers-reduced-motion и управление с клавиатуры.
- Контейнер не хранит пользовательские данные и не требует постоянного диска. HTTPS завершается на ingress облачного сервиса.

## Следующие этапы после первой версии

Первая версия реализована и проверена 13 октября 2026 года. `npm run check` проходит: HTML/CSS/JS около 138 KB, изображения около 244 KB. Playwright-прогон прошёл непосредственно через Docker: семь ширин от 320 до 1920 px, отдельно короткие экраны 390×667 и 320×568, фильтры, корзина, восстановление, реальные скачивания, формы и диалоги. Ошибок JavaScript, неудачных загрузок и горизонтального скролла страницы не обнаружено.

Образ `neuroshift:local`: Linux amd64, пользователь 101:101, около 60 MiB. Проверен запуск с read-only filesystem, временным `/tmp` и без Linux capabilities. Контейнер `neuroshift-preview` healthy. Локальный просмотр: http://127.0.0.1:8088. Отчёт и скриншоты: `test-results/` (не входят в Git и образ).
