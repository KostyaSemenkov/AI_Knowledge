# Бриф для работы с ИИ

Учебный шаблон NEUROSHIFT. Заполняйте только поля, которые нужны вашей задаче.

## 1. Задача

- Рабочее название: ____________________
- Что нужно подготовить: ____________________
- Для какого решения или следующего действия нужен результат: ____________________
- Что не входит в задачу: ____________________

## 2. Аудитория

- Кто будет читать или использовать результат: ____________________
- Что эти люди уже знают: ____________________
- Какой вопрос или затруднение нужно решить: ____________________
- Подходящий тон: ____________________

## 3. Исходные материалы

- Проверенные факты: ____________________
- Текст, заметки или таблицы для обработки: ____________________
- Дата и источник исходных сведений: ____________________
- Что пока неизвестно: ____________________

Удалите из материалов пароли, ключи и ненужные персональные данные.
Проверьте, разрешено ли передавать рабочие сведения выбранному сервису.

## 4. Ограничения

- Язык: ____________________
- Объём или время чтения: ____________________
- Допустимые источники: ____________________
- Какие утверждения и обещания нельзя добавлять: ____________________
- Что делать с отсутствующими данными: ____________________

## 5. Формат

- Тип результата: письмо / таблица / план / инструкция / другой: ____________________
- Обязательные разделы или поля: ____________________
- Пример подходящей структуры: ____________________
- Нужно ли показать допущения и открытые вопросы: ____________________

## 6. Критерии приёмки

- [ ] Все обязательные факты сохранены.
- [ ] Новые неподтверждённые сведения не добавлены.
- [ ] Читателю понятен следующий шаг.
- [ ] Формат, объём и тон соблюдены.
- [ ] Числа, даты и ссылки проверены.
- [ ] Дополнительный критерий: ____________________

## 7. Сборка промпта

```text
Подготовь [результат] для [аудитория].
Он нужен, чтобы [следующее действие или решение].
Используй эти исходные данные: [материалы].
Соблюдай ограничения: [ограничения].
Дай ответ в формате: [разделы или поля].
Критерии качества: [критерии].
Если данных не хватает, [порядок работы с пробелами].
```

## 8. Журнал итераций

| Версия | Что изменили | Что стало лучше | Что ещё проверить |
| --- | --- | --- | --- |
| 1 | Исходный запрос | | |
| 2 | | | |
| 3 | | | |

Сохраняйте только полезные варианты. Ценность шаблона определяется качеством результата в вашей задаче.
