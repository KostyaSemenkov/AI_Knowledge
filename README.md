# NEUROSHIFT

Лёгкий лендинг-магазин обучения промпт-инжинирингу и работе с ИИ. HTML, CSS и JavaScript ES modules без внешних runtime-зависимостей, CDN, удалённых шрифтов и сборщика. Для публикации нужен только Nginx.

## Локальный запуск

Нужен Node.js 20 или новее; установка npm-пакетов не требуется. В PowerShell из папки проекта:

```powershell
npm run check
npm run dev
```

Откройте http://127.0.0.1:4173. Параметры сервера можно задать через окружение:

```powershell
$env:HOST = "0.0.0.0"
$env:PORT = "4174"
npm run dev
```

Локальный сервер обслуживает только публичные файлы сайта. `npm run check` проверяет JavaScript, наличие локальных ресурсов, HTML-якоря, совместимость HTML с CSP и бюджет HTML/CSS/JS до 150 KB и изображений до 1.5 MB без сжатия. Проверка не заменяет просмотр интерфейса в браузере.

## Браузерная проверка

Для разработки предусмотрен отдельный Playwright-прогон. Он не входит в образ и не нужен посетителям сайта. Установите необязательный пакет `npm install --no-save playwright`, запустите сайт и выполните `npm run test:browser`. По умолчанию используется установленный Google Chrome; для Edge задайте `$env:BROWSER_CHANNEL = "msedge"`. Другой адрес сайта задаётся через `$env:SITE_URL`, например `http://127.0.0.1:8080`.

Прогон проверяет фильтры, корзину и восстановление состояния, валидацию заявки, реальные скачивания, примеры промптов, диалоги, мобильное меню и отсутствие горизонтального скролла на семи размерах экрана. Скриншоты и отчёт сохраняются в игнорируемую Git папку `test-results`.

## Контейнер

Образ использует [официальный Nginx Alpine](https://hub.docker.com/_/nginx), запускается с UID/GID `101:101`, слушает порт `8080` и отвечает `200 ok` на `/healthz`. Node.js и npm в финальном образе отсутствуют. Dockerfile копирует только HTML, конфигурацию сервера и публичные ресурсы.

```powershell
docker build --pull -t neuroshift:local .
docker run --rm --name neuroshift -p 8080:8080 --read-only --tmpfs /tmp:rw,noexec,nosuid,size=16m,mode=1777 --cap-drop ALL --security-opt no-new-privileges:true neuroshift:local
```

Сайт: http://localhost:8080. Проверка готовности:

```powershell
Invoke-WebRequest http://localhost:8080/healthz
```

Альтернативный запуск через Compose:

```powershell
docker compose up --build -d
docker compose ps
docker compose down
```

Nginx сжимает текст, разрешает только локальные скрипты и стили через CSP, добавляет заголовки безопасности, возвращает `404` для отсутствующих ресурсов. HTML, CSS и JavaScript перепроверяются при посещении; изображения кешируются на сутки. При замене изображений для немедленного обновления меняйте имя файла. Логи идут в stdout/stderr. Для read-only root filesystem нужен записываемый `/tmp`; остальное состояние контейнер не хранит.

## Container Apps

1. Соберите образ для архитектуры выбранного облачного окружения, загрузите его в свой container registry и укажите этот образ в Container Apps.
2. Включите внешний HTTP ingress с target port `8080`. Публичный HTTPS завершает ingress; сам Nginx принимает HTTP внутри окружения.
3. Настройте HTTP startup/readiness/liveness probes на путь `/healthz`, порт `8080`. Docker `HEALTHCHECK` удобен локально; облачные probes задаются отдельно.
4. Постоянный диск и секреты для этой версии не нужны. При read-only root filesystem предоставьте записываемый временный том `/tmp`.
5. Для экономии допустим `min replicas = 0`, если подходит задержка первого запроса после простоя. Для постоянной готовности выберите минимум одну реплику. Корзина хранится в localStorage браузера и не зависит от числа реплик.

## Содержание и ограничения

- Курсы, цены, FAQ, примеры промптов и проекты редактируются в `assets/data.js`; разметка в `index.html`, оформление в `assets/styles.css`, взаимодействия в `assets/app.js`.
- Цены и примеры учебных проектов демонстрационные. Перед коммерческим запуском нужны реальные программы, стоимость, контакты и юридические реквизиты.
- Корзина сохраняется только в браузере. Сайт подготавливает и скачивает файл заявки; заявка автоматически никуда не отправляется.
- Реальная отправка заявок, приём платежей, личный кабинет и API искусственного интеллекта не подключены. Для них потребуется отдельная серверная интеграция. Секреты нельзя добавлять в клиентский JavaScript.
- Материалы в `assets/materials` доступны как Markdown-файлы. Изображения локальные, в `assets/media`.
- Иконки Lucide находятся в локальном SVG-спрайте `assets/icons.svg`; лицензия поставляется в `assets/LUCIDE-LICENSE.txt`. Значок сайта: `assets/favicon.svg`.
- Архивный исходник `assets/media/gallery-sheet.webp` остаётся в репозитории и исключён из контейнера и бюджета поставляемых изображений.
- План работ: [PLAN.md](PLAN.md).
